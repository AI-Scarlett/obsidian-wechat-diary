## 0. 一句话

用户在设置页定义「切换关键词 → 文件夹」规则。微信里发一条以关键词开头的消息, 之后的消息都记进那个文件夹(每个文件夹有自己的当日文件); 说「退出关键词」或「结束」回到默认日记; 跨逻辑日(凌晨 4 点)自动回默认。非默认文件夹的每条回执都带文件夹名, 错了当场看得见、「撤回」能救。

## 1. 已拍板的骨架(谷雨 2026-08-27, 不再讨论)

- 命名直白: 设置页区块叫**「切换文件夹」**, 字段叫**「切换关键词」「退出关键词」**。
- **切换式**, 不是每条前缀: 「入梦 昨晚飞了」= 切到梦境文件夹 + 把"昨晚飞了"记进去; 之后的消息继续记在那里。
- **三层防错位保险**: ①非默认分区每条回执必须带文件夹名; ②跨逻辑日自动回默认; ③「结束」兼作退出。
- 退出词有内置默认(**「回日记」**, §9 B2 定), 用户可改可加; 退出词只在分区里才是命令。
- 防误触: 关键词只在"单独一条"或"关键词+空格/标点+内容"两种形态生效; 打错/未定义的关键词整句照记, 一个字不吞。
- 关键词 ≤4 个中文字, 一个文件夹可以配多个关键词。
- 每分区独立当日文件+段数(同一份数据契约格式); 「在吗」报当前在哪。
- 不做分区独立的提醒(§8); 任一文件夹今天记过就不催(§9 B1)。

## 2. 细节定案(Claude 推荐 → 谷雨 8/27「继续」→ 审稿修订)

| # | 议题 | 定案 |
|---|------|------|
| 2.1 | 退出词能不能"退到另一个文件夹" | **不能, 只回默认日记**。想去 B 直接说 B 的关键词(A 里说 B 的关键词=切到 B)。 |
| 2.2 | 「晚安」在分区里说 | **晚安是"一天"级别**: 封当天所有有内容的文件(默认+各分区)、报总段数、回到默认日记。**在默认日记里说「晚安」同样封全部**(不切换)。 |
| 2.3 | 「结束」在分区里说 | 封**当前分区**的当日文件 + 回默认日记(骨架③)。在默认日记里说「结束」= 现状不变。 |
| 2.4 | 「撤回」跨分区 | **撤同一逻辑日内全局最后一条**(不管落在哪个文件夹)。跨天后与现状一样只碰今天的文件。紧跟在"单独切换/退出"之后的「撤回」= 撤销那次切换, 不动文件(§9 B3)。 |
| 2.5 | 语音转写形态 | 「入梦。昨晚飞了」「入梦，，昨晚」「入梦。」都算: 关键词后面的**一串**分隔符(全/半角标点+空白)整体吃掉; 「入梦。」单独一条 = 单独一条。 |
| 2.6 | 分区里的夜间收尾提示 | **不做分区特殊版**。现有提示教的是「晚安」这个天级动作, 与分区无关, 维持原样。 |

## 3. 数据模型

```js
// settings (data.json, 有 UI)
folderRules: [ { keywords: ["入梦", "梦"], folder: "梦游太虚幻境" }, ... ],   // 默认 []
exitKeywords: ["回日记"],                                                      // 默认 ["回日记"]

// session (data.json, 运行时)
folder: "",                                   // 当前所在分区 = 规则里的 folder 路径; "" = 默认日记(settings.diaryFolder)
last_write: { folder: "", date: "" } | null,  // 最近一次成功写入落在哪(「撤回」跨分区的依据); 只在 date === 今天(逻辑日)时有效
switch_undo: { from: "" } | null,             // 上一条是"单独切换/退出"时记来源文件夹, 供「撤回」撤销切换; 任何成功写入置 null

// ilink.fileMd5s 条目: { md5, path, root }    // root = 写入时的根目录(老条目没 root 按默认日记算)
```

- `folder` 存路径不存关键词: 规则改关键词不影响正在进行的会话; 规则被删则下一条消息时静默回默认并告知(§5.7)。
- `last_write` 的唯一写入口是 `_noteWrite`(3839, 六个写入路径的公共出口); 生产路径上六个写入点的 dateStr 永远是 undefined, 所以 **DiaryWriter 的每个写入方法在返回值里带上实际用的 `{ day, folder }`**, `_noteWrite(res)` 从结果取。`_loadOrReset` 翻页时清空 `last_write`(与清 `folder` 同一处)。
- `DEFAULT_DATA` 必须每次新建数组: `Object.assign({}, DEFAULT_SETTINGS, { folderRules: [], exitKeywords: [...] })`——现有浅拷贝(4578)会让老 data.json 用户的 `settings.folderRules` 指向模块常量本体, push 一条等于改常量, bindtest 的 `newPlugin` 也会跨用例串。onload 后对 `folderRules/exitKeywords` 做形状清洗(非数组丢、非字符串项丢、超长截; 用户会手改 data.json)。
- 分区文件夹结构与默认日记**完全相同**: `<分区>/YYYY/YYYY-MM-DD.md` + `<分区>/attachments/YYYY/…`。**分区可以放在日记文件夹里面或外面, 都不串**(已核 diaryPath/attachmentPath/countMessages: 各根下 YYYY/ 与 attachments/ 都是各自子树)。
- 契约 v1.3 加一段: "可能有多个根目录(用户在插件里配的分区), 每个根目录内部格式一致、**各自自包含——附件只引用本根目录 attachments/ 下的文件, 不跨根引用**"(B4 选本地复制后这句是真话)。文件内部格式一字不改, 019 与任何读取方无需改动。frontmatter 不加分区字段。

## 4. 设置页(「切换文件夹」区块, 放在「日记文件夹」下面)

```
切换文件夹
  用一个关键词把之后的消息记到另一个文件夹。关键词选日常说话用不到的词, 每个不超过 4 个字; 多个关键词用逗号隔开。
  ┌──────────────────────────────────────────────────────────────┐
  │ 切换关键词 [入梦, 梦        ]  文件夹 [梦游太虚幻境      ] [删除] │
  │ 切换关键词 [感悟            ]  文件夹 [玄学感悟          ] [删除] │
  └──────────────────────────────────────────────────────────────┘
  [+ 添加规则]
  退出关键词  [回日记          ]   在分区里说这个词回到默认日记, 「结束」也能回。同样选日常说话用不到的词。
```

- 文件夹输入复用「日记文件夹」的输入即搜索组件(`AbstractInputSuggest`), 不存在的路径写入时自动创建(与现状一致)。
- **编辑与落盘**: 规则列表在 `display()` 时从 settings 复制一份 draft; 校验在输入框 blur / Enter 时跑(不是每键 onChange——否则打「感悟」到「感」时就是一条合法规则, 实时改路由; 第二行打到「梦」就撞第一行弹 Notice); 通过的才整体**赋值**回 `settings.folderRules`(只含完整规则, 不用 push); 正在编辑的行不参与匹配; 不合法时**只不落盘, 不回退输入框**(别抄提醒时间那支"越界回退", 否则「梦境」输不进去)。
- **关键词校验**(`validateFolderRules`, 纯函数进 bindtest):
  1. 去空白后非空, 每个 ≤4 码点; `stripNoise(kw) !== kw` → 拒(含标点/引号/emoji); 存与比都 `toLowerCase()`(英文关键词「OK」「ok」行为一致)。
  2. `detectIntent(kw)` 的 intent 不是 DIARY, 或 `forced` → 拒, 文案「「晚安」和内置命令重复, 换一个」。用 detectIntent 而不是查词表: 「啦→了」补形态、复读折叠、撤回尾巴白名单、多段告别、`START_DIARY_PHRASES` 的 includes 全部自动覆盖(实测 `normalizeIntent("记完啦")`=「记完」不在任何表里但 `detectIntent` 认 FINALIZE), 词表以后演进也不用同步。顺带覆盖「开始」「早」「测试」等 START/CHAT 单字。
  3. `LEAD_ACK_RE`(2707) 全匹配(m[0].length === kw.length) → 拒, 文案「「好」是应答词, 换一个」——`detectIntent("好")` 返回 DIARY, 这条不能省; 否则「好，结束」「嗯 撤回」「好的好的晚安」全部变成切换 + 把命令词记成内容, 打穿 D9。
  4. 单字 `TAIL_PARTICLES`(吧/啊/啦…) → 拒; 「记」→ 拒(与「记：」逃生口冲突)。
  5. 全部关键词(含退出词)两两不重复。
- **文件夹校验**: 抽纯函数 `sameRoot(a, b)`(normalizePath + 去尾斜杠 + 空串视为「日记」, 与 diaryPath 兜底一致), 三处复用: ①规则文件夹非空且 `!sameRoot(folder, diaryFolder)`, 规则之间不重复(同一文件夹想配多个词写在同一行); ②「日记文件夹」onChange / selectSuggestion 撞规则文件夹时 Notice + 回退(现状这里零校验, 先配「感悟→玄学感悟」再把默认改成「玄学感悟」就同根, 「在吗」「晚安」把同一文件数两遍); ③运行时 `matchFolderSwitch` 前过滤掉 `sameRoot(rule.folder, diaryFolder)` 的规则(手改 data.json 也挡得住)。
- 半截输入(只填了关键词没填文件夹)不报错也不生效——规则"完整"才参与匹配。
- **没配任何规则时, 一切行为与 0.3.1 完全相同**(退出词也不匹配: 没有分区可退, 「回日记」照记为内容; 帮助/在吗/撤回/晚安文案与现有断言逐字一致)。**不在分区里时同样如此**: 退出词只在 `session.folder !== ""` 时参与匹配(§9 B2)。

## 5. 识别与路由

### 5.1 匹配规则(纯函数 `matchFolderSwitch(raw, rules, exitKeywords, currentFolder)`)

1. 「记：xx」逃生口先于一切: `记：入梦` 原样落进当前分区。
2. 取 `raw` 从头到第一个分隔符之前的部分为 `head`; 分隔符 = 空白 + 全/半角标点(`,，、;；。.!！?？:：~～` 及 `STRIP_CHARS`); **head 之后连续的一串分隔符整体吃掉**(与 `SEGMENT_SEP_RE` 同款 `+`; 语音转写常出「入梦。 昨晚」「入梦，，昨晚」, 只吃一个会把标点写进文件)。
   `head` 过 `stripNoise`(剥尾部 emoji/符号、头部引号)+ `toLowerCase` 后与关键词**精确比对**(不做前缀、不做包含)。
3. `rest` = 分隔符串之后的全部内容(去首尾空白)。
   - head 命中切换词, rest 空 → **只切换**;
   - head 命中切换词, rest 非空 → **切换 + 把 rest 原样记进目标分区**(rest 不再走命令识别: 「入梦 晚安」把"晚安"两个字记进梦境; 「入梦 叫我小明」记内容不改称呼——所以切换分支直接调 `_writeEntry`, 不经 `_handle`);
   - head 命中退出词**且 currentFolder !== ""** → 同上两种形态, 目标 = 默认日记。在默认日记里退出词不参与匹配, 「回日记」「回日记，xx」整句照记(§9 B2);
   - 不命中 → 整句进现有 `detectIntent`, 一个字不动。
4. **不剥前置应答词**(「好，入梦」不算切换, 整句照记); 前置应答词不能配成关键词(§4 校验 3 会拒)。
5. 「入梦」句首无分隔符跟着字(「入梦想还是要有的」→ head = 整句)自然不命中。

### 5.2 状态机(在 `DiaryAgent._dispatch` 里, `_loadOrReset` 之后、`detectIntent` 之前)

| 现在在 | 收到 | 动作 | 回执 |
|---|---|---|---|
| 日记 | 切换词 X (单独) | session.folder = X; `switch_undo = {from: ""}` | `切到「梦游太虚幻境」了, 接下来发的都记在这里 (说「回日记」回日记)` |
| 日记 | 切换词 X + 内容 | 切换 + 写入 X(写入把 switch_undo 置 null) | `记下来啦~ 「梦游太虚幻境」第 1 段 ✍️ (切到这里了, 说「回日记」回日记)`——**凡本条导致 session.folder 变化的写入回执都挂这一次退出提示**(误触几乎总是带内容的形态, 缺了它误触的人会试「退出」「返回」全被记进分区); 之后各条维持短回执 |

| 日记(配了规则) | 「在吗」 | 不落库 | `在的~ 现在在「日记」, 今天已记 N 段 ✍️`(N=0: `在的~ 现在在「日记」, 想记什么直接发`)——骨架说"报当前在哪", 跨天/规则被删回默认之后用户最想确认位置, 不能只靠"没出现文件夹名"反推; 没配规则维持原句 |
| 任意 | 「帮助」 | — | `helpText(rules, exitKeywords)`, 见 §6 |

- 凡是把多个文件夹并列的地方(「在吗」「晚安」明细)用 `settings.diaryFolder` 的**实际名字**(朋友的默认文件夹可能叫「生活」); 单独出现的「回到日记了」这类泛称维持不变(welcomeText 也这么用)。
- 分区里的回执**不挂** FIRST_OF_DAY_PREFIX("今天的第一条记录, 已经记录在新开的文件里啦")——文件夹名已经说明位置; 开页 tips(撤回/帮助)也不挂(默认日记每天第一条已经给过)。
- `_noteWrite`(提醒 streak 清零、夜间提示依据、last_write、清 switch_undo)对所有分区的写入一视同仁——写了东西就是"今天记了"。**每日提醒同口径(B1)**: `_reminderTick` 对 `_allFolders()` 逐个 `countDay(day, folder)`, 遇 >0 即停不催; 现有"countToday=0 预判先跑"不动(关着提醒/不到点时零文件读取)。提醒文案不改。

#### 5.2.1 「撤回」

1. `session.switch_undo` 非空(上一条是单独切换/单独退出, 之后没有任何成功写入)→ **撤销切换**: `session.folder = switch_undo.from`, 清标记, 不动文件, 回 `好的, 取消切换, 还在「{from 或 diaryFolder}」里`。再说一次「撤回」才走下面的删内容。("切换前文件夹"可能是另一个分区——这是撤销, 不是 2.1 否掉的"退到指定文件夹"。)
2. `last_write && last_write.date === logicalTodayStr()` → 撤 `last_write.folder` 的今天文件的最后一条(规则删了文件还在, 最后一条确实写在那, 撤那里才对)。
3. 否则 → 撤**当前分区**的今天文件(与现状一致: 跨天后今天没文件 → 没东西可撤)。这保证 `folderRules` 为空时 last_write 永远等价于"今天的默认日记", §4 末尾的承诺才成立。
4. 撤回后 `last_write` 不清, 仍指向那个文件: 连说两次撤回撤同一文件的倒数第二条(全局顺序跨文件无法还原, 写进帮助不写进回执)。
5. 撤空的回执按位置分: 分区里 `「梦游太虚幻境」今天还没记东西, 没东西可撤`; 默认日记维持 `今天还什么都没说呢, 没东西可撤哦`(在分区里说这句是假话——用户今天在日记里说了很多)。

### 5.3 跨逻辑日

- `_allFolders()` = 默认 + 每条规则的文件夹 + `session.folder`(去重; session.folder 可能指向已删规则的路径, 不加进去那个文件夹昨天的文件永远封不上)。
- `_loadOrReset` 翻页时: 对 `_allFolders()` 逐个 `finalizeDay(entered_date)`(没文件=空操作; 一个失败不影响其余), 记 `wasInFolder = session.folder !== ""`, 然后 `session.folder = ""`、`session.last_write = null`、`session.switch_undo = null`。返回 `{ sealedAny, wasInFolder }` **两个独立信号**(现状把告知绑在 `finalizeDay` 的 sealed 上——昨晚「晚安」封全部后又「入梦 又梦到了」补一条再睡, 翻页时全是 already, 没有任何括号但 folder 已清空, 早上接着说梦落进日记、回执没有文件夹名——正是骨架②要防的静默错位)。
- 告知文案(仍挂 `cross.expiredNotice` 位置, 一条回执一个括号; `willNotice` 改为"任一告知存在"):
  - sealedAny + wasInFolder → `(昨天的已自动收尾, 已回到日记 📖)`
  - 只 wasInFolder → `(新的一天, 已回到日记 📖)`
  - 只 sealedAny → 现有 `(昨天的已自动收尾, 翻开新的一页 📖)`
  - 都没有 → 不告知
  - **本轮消息本身又切换了**(跨天后第一条就是「入梦 xx」)→ 不说「已回到日记」(与紧接的「「梦游太虚幻境」第 1 段」矛盾), 只保留 sealedAny 对应的现有句或不告知; 切换回执自带文件夹名已说明位置。告知在 `_dispatch` 末尾按"本轮结束时 session.folder 是否仍为空"决定。

### 5.4 封存聚合 `finalizeAll(day, folders)`

- 逐个 `finalizeDay`, 返回 `{ status, n, afterSeal, details: [{folder, n, status}], failed: [folder] }`: `n = Σn`; status: 任一 sealed → sealed; 否则任一 afterSeal>0 → already(afterSeal=Σ); 否则全 empty → empty; **全部** error → error; **部分** error → 按成功部分出文案, 尾部加一句 `(「X」的收尾标记没写上)`——失败必须响亮, 但要准确(现状 FINALIZE_FAIL_REPLY「收尾标记没写上」在默认已经写上时是假话, 重发「晚安」又变 already)。
- `finalize_count` / `reminded_date` 记账在"不是全 error"时做(沿用 D9「说过收尾词就计数」)。
- `signoffReply` 的 `{n}` = 总数; 明细括号只在 ≥2 个文件有内容时出现; "只有 1 段"的单数文案按总数判。
- 调用方: 「结束」传 `[session.folder]`(默认日记里 = `[""]`, 现状不变); 「晚安」传 `_allFolders()`; `_loadOrReset` 复用(sealedAny = 任一 sealed)。

### 5.5 媒体

图片/文件/视频/语音原声落 `<当前分区>/attachments/YYYY/`, 规则不变(靠 §5.2 的 folder 透传)。

**重复文件的 md5 复用(B4 = 本地复制)**: `fileMd5s` 条目加 `root`; `_findKnownMd5` 返回全部命中(文件仍在的)条目, **优先同根**: 同根命中 → 现状, 只插 wikilink; 只有跨根命中 → `vault.readBinary` 读本地那份, 走现有 `writeAttachment` 存进当前根的 attachments 并 `_rememberMd5(md5, newPath, root)`; 老条目没 root 的按默认日记算。零网络、不触 #193(重发同一文件微信给错密钥的坑), 契约"各根自包含"成立。回执沿用 `fileReusedReply/videoReusedReply`(对用户来说都是"之前收过, 直接用了")。fakeVault 桩补 `readBinary`。

### 5.6 首次见面

`profile.state !== "active"` 的第一条如果是切换词: 先切换/记录, 再接欢迎语(与现在"第一条是图片先收再介绍"同规则)。第一条是**纯切换词(rest 空)**: 回执 = 切换文案 + 换行 + 欢迎语, 且欢迎语里「记的东西在「{diaryFolder}」文件夹」那句在切换态下改成「记的东西在「{当前文件夹}」」(现状 `welcomeText` 2457 硬写默认文件夹, 与刚切到的分区打架)。

### 5.7 规则被删/改

`session.folder` 指向的路径不在当前规则里(用户删了规则) → 下一条消息静默回默认, 回执前挂一句 `(「梦游太虚幻境」的切换规则已删, 回到日记)`。改关键词不影响(存的是路径)。

## 9. 审稿轮抛出的 4 道产品选择题——谷雨 2026-08-27 拍板

**B1 每日提醒口径 → 任一文件夹今天记过就不催。** 背景: v1 三处口径打架(`_noteWrite` 对任何写入清 streak; FINALIZE 不分文件夹压掉当天提醒; 只有 `_reminderTick` 的 countDay 只读默认日记)——只在「工作」分区记的人 21:30 会收到"今天还什么都没记"(假话), streak 永远归零, D10 的"3 天闭嘴"达不到。定案: `_reminderTick` 对 `_allFolders()` 逐个 countDay 遇 >0 即停; 预判逻辑不动; 文案不改; 三处统一为"写了东西 = 今天记了", 与 D10 原话同口径。

**B2 退出词 → 只在分区里才是命令; 默认词换「回日记」。** 背景: 实测现状 `detectIntent("回来。")`、`detectIntent("回来，吃了降压药")` 都照记; v1 让退出词不分位置都当命令, 配过一条规则后默认日记里语音「回来。」不落库、「回来，路上堵死了」静默少字。「回来」是备忘录人群的高频状态词, 与 D9「可能是内容就不收」冲突, 且是内置默认不是用户自选, 吞字责任归产品。定案: `matchFolderSwitch` 收 currentFolder, `session.folder === ""` 时退出词不参与比对, 整句照记, 与没配规则时完全一致; 删掉「本来就在日记里~」那行(想确认位置有「在吗」); 默认词「回日记」(3 个字, 与字段语义一致, 语音说得清, 日常说话用不到), 用户随时可改。

**B3 手滑切错后「撤回」→ 撤销切换, 回到原来的文件夹。** 背景: 在日记里记了「今天开会很累」, 手滑单独发「感悟」切到玄学感悟, 第一反应「撤回」——想撤的是切换; v1 会删掉「今天开会很累」且人还留在玄学感悟, 一次手滑三步补救。定案: `session.switch_undo = {from}` 在单独切换/单独退出时记来源, 任何成功写入置 null; UNDO 先看它, 非空则 `session.folder = from`、清标记、不动文件, 回「好的, 取消切换, 还在「{from}」里」; 再说「撤回」才删内容。from 可能是另一个分区——这是撤销, 不是 2.1 否掉的"退到指定文件夹"。

**B4 重复文件跨分区 → 本地复制到当前分区, 不跨根链接。** 背景: `_findKnownMd5` 全局命中就插对方根目录的 wikilink, 与"文件夹即管理"相悖, 契约也不能写"互不引用"; "按根隔离重新下载"会把用户推进 #193 解密坑, 一致否掉。定案: `fileMd5s` 条目加 root, 优先同根命中只插链接; 跨根命中 `vault.readBinary` 本地复制到当前根的 attachments 并记新条目; 零网络; 契约写"各根自包含"。代价: 同一文件在两个根各占一份磁盘(可接受)。

## 10. 记录在案不改(审稿轮裁决)

- 「梦」作为示例、单字关键词不加 Notice: 「梦」是谷雨拍板里亲自举的例子, 设置页已有"选日常说话用不到的词", 关键词是用户自选; 误触由 §5.2 切换+内容的退出提示兜底。
- 撤回只动今天(03:58 写、04:02 撤撤不到): 与 0.3.1 相同, 接受; 不走"保留跨天 last_write + 回执说『昨天的』"那条路(要改掉 §4「完全相同」的承诺, 得不偿失)。
- 撤回连说两次撤同一文件的倒数第二条: 明确边界, 写进帮助。
- 设置页半截关键词那一秒恰好被消息命中: 概率极低, draft/blur 方案顺手消除。
- 默认与分区同根要用户故意改「日记文件夹」才会发生: 后果只是数两遍不丢内容, §4 校验是纵深。
- 驳倒未采纳: 「入梦吧」「回来啦」带语气词不匹配(关键词严格比对是设计意图, 用户可把变体一起配上); 「回来 晚安」把"晚安"记进日记(rest 不走命令识别是 §5.1 定义); 分区嵌套需要禁止(已核不串, §3 写明允许)。
